# claude-skill-new-project

Skill de Claude Code para arrancar un proyecto de software nuevo — arquitectura, convenciones, testing y documentación decididas antes de escribir código, no improvisadas sobre la marcha.

En construcción. El contenido todavía no está escrito.

## Instalación

Clonar (o agregar como submódulo) dentro de `.claude/skills/new-project/` en el proyecto donde se quiera usar, o en `~/.claude/skills/new-project/` para tenerla disponible en todos los proyectos.
